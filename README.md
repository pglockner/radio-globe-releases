# Radio Globe: test builds

Android builds of [Radio Globe](https://jukenzie.com/radio-globe/), live radio from around the world on a globe, for friends who are testing it. The app's source is in a private repository; only the builds live here, under [Releases](https://github.com/pglockner/radio-globe-releases/releases).

The newest build is always at:

https://github.com/pglockner/radio-globe-releases/releases/latest/download/radio-globe.apk

Install it on an Android phone by opening that link in the phone's browser, then the downloaded file. The phone asks once to allow installs from the browser. Later builds install over the earlier ones and keep your favorites.

Something wrong, or an idea? In the app, open a station's card and tap **Feedback** at the bottom; it sends the app's diagnostic log along with your note. Or write to support@jukenzie.com.
